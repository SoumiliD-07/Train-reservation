1. Arrays (Seat Mapping)

Arrays provide O(1) constant time lookup for seat status (0 for vacant, 1 for occupied). In C, `int seats[10]` acts as a fixed physical representation of the coach layout.

  • Fixed size contiguous memory allocation.
  • Instant seat lookup via index.

2. Linked Lists (Bookings)

Dynamic allocation of confirmed passenger tickets. As bookings occur dynamically, dynamic `Node*` pointers prevent memory waste and allow arbitrary node deletion on cancellation.

  • Dynamic memory sizing via `malloc()`.
  • Dynamic insertion & node pointer unlinking.

3. FIFO Queue (Waiting List)

Fairness algorithm adhering to First-In-First-Out. Passengers who try to book full trains enter the tail (`rear`). When a seat is freed, the head (`front`) passenger is dequeued and promoted.

  • Strict Enqueue (`rear`) & Dequeue (`front`).
  • Ensures fair priority reservation promotion.

Reservation & Cancellation Life Cycle

STEP 1: BOOKING REQUEST

System checks `seats[10]` array for `0`. If found, allocates index, appends to Linked List.

STEP 2: OVERFLOW TO QUEUE

If all array indices are `1`, enqueue passenger onto the FIFO Queue waiting list.

STEP 3: CANCELLATION & PROMOTION

Removing node from Linked List triggers `dequeue()`. Next queued passenger inherits freed seat.
